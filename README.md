# FirstSpark｜点火计划

**Start small. Learn from reality.**

把“我想做”，变成一个今天能开始、做完有答案的小行动。

FirstSpark 是一个以中文交互为默认的 AI Agent Skill，帮助你启动新项目、验证想法，或重新推进停滞的项目。它把讨论落到一个关键行动、真实反馈，以及明确的继续、调整和停止条件。

An instruction-based skill for starting projects with one reversible action, real-world feedback, and clear decision criteria. The default interaction language is Chinese; you can request another language.

## 它会帮你做什么

- **探索新想法：** 找出最需要验证的假设，用小实验获得反馈。
- **推进明确任务：** 确认验收条件和关键依赖，开始交付。
- **重启停滞项目：** 找出上次具体卡住的位置，处理真正的障碍。

它会区分“做了事情”和“事情有了进展”。完成打卡、获得口头称赞或整理了大量资料，都不自动等于假设成立。

## 安装到 Codex

将本仓库克隆到个人技能目录：

```bash
git clone https://github.com/Jasonfu828/first-spark.git "$HOME/.agents/skills/first-spark"
```

目标目录需尚不存在；如果已安装同名技能，先检查已有内容，不要直接覆盖。也可以下载仓库，将整个文件夹命名为 `first-spark`，放入个人技能目录。此技能没有运行脚本、API Key 或额外服务依赖。

按照 [Codex 官方技能说明](https://learn.chatgpt.com/docs/build-skills)，新技能通常会自动被发现；如果没有显示，可以重启 Codex。不要在多个扫描目录重复安装同一个技能。

## 使用

在项目对话里输入：

```text
使用 $first-spark 帮我启动这个项目：
我想做……
目前已经有……
可投入的时间和资源是……
最不确定的是……
```

不需要把所有问题都回答完整。技能会先利用已有上下文，只追问会改变下一步的信息；适合暂定的内容会标明假设。

也可以直接这样开始：

```text
使用 $first-spark。我想验证一个给自由职业者用的报价工具，
每周有三小时，目前只有想法。先帮我找到一个能获得真实反馈的动作。
```

```text
使用 $first-spark。下周需要交付一份已确定范围的内部报告。
请从当前材料和验收要求出发，确定第一个交付动作。
```

```text
使用 $first-spark。这个项目停了两周。
我完成了原型，但一直没安排测试，帮我看看具体卡在哪里。
```

## 你会得到什么

一张简洁的启动卡，包含目标与边界、已有证据、核心假设或依赖、一个关键行动、启动约定、时间与成本上限、反馈和调整条件。

下面是虚构的输出示例，不是市场验证结果：

| 项目 | 本轮安排 |
| --- | --- |
| 目标 | 了解自由职业者制作报价时是否存在反复出现的麻烦 |
| 核心假设 | 报价准备耗时，且现有工具不能很好地处理某个具体环节 |
| 一个关键行动 | 邀请一位目标用户，复盘其最近一次真实报价经历 |
| 启动约定 | 明天早餐后，花十五分钟准备问题并发出邀请 |
| 最低版 | 明确一位合适的联系人和一个问题；不能长期停留在准备阶段 |
| 反馈 | 最近发生的事件、当前处理方式、时间或金钱成本 |
| 回看 | 一周后检查联系与交流结果；无回复先检查触达，口头称赞不当作需求验证 |
| 调整条件 | 若该问题不常发生，检查对象或假设，暂不扩大开发投入 |

一次交流提供线索，不代表市场。项目的反馈周期、成本和风险不同，试验期限也应相应调整。

## 做不下去怎么办

FirstSpark 会检查提示、技能、时间与资源、协作、评价压力、目标相关性，而不是简单要求“更自律”。它允许缩小范围、寻求协助、改变方法，也允许暂停或退出。

风险分析仅在能改变下一步时展开。对高成本、难撤回的决定，先做必要核实；不把“行动起来”当作跳过评估的理由。

## 来源与边界

这套流程受到 The Tim Ferriss Show 的讨论，以及实施意图、行为改变与事前失败分析等方法启发。具体资料与局限见 [references/evidence.md](references/evidence.md)。

这是一个工作性组合，整套流程尚未经过统一效果验证。小行动不保证自信迁移、项目成功或收入增长。价值取舍由使用者决定，技能不替代专业评估，也不自行诊断健康问题。

本技能不会因为被加载就获得额外外部操作权限；发送消息、购买、发布等仍需要符合用户授权范围。
